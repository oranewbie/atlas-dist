# Atlas Studio — AI 와 함께 일하는 작업대

> 현재 버전 **v0.1.29** (프리뷰, Windows) · 다운로드: [Releases](https://github.com/oranewbie/atlas-dist/releases) 의 `studio-v*` 태그
>
> 처음이라면 이 순서를 권해요: **이 소개** → [활용 사례](use-cases.md) → [쉽게 따라하기](tutorial.md) → [용어집](glossary.md) → [사용자 매뉴얼](manual.md)

## 한 줄로 말하면

**"일하는 방법을 담아 두면, AI 와 내가 그 방법대로 함께 일하는 데스크톱 앱"** 이에요.

AI 채팅은 편하지만, 실제 일에는 **순서**가 있고 **결과물**이 있고 **"이 정도면 됐다"는 기준**이 있어요.
매번 채팅창에 같은 설명을 반복하다 보면 결과가 들쭉날쭉해지죠.

Atlas Studio 는 이 문제를 이렇게 풀어요.

1. **일을 단계로 나눠 둬요.** 예: ① 재료 모으기 → ② 초안 쓰기 → ③ 검토하기
2. **단계마다 "어떻게 하는지"를 절차서로 남겨요.** AI 는 그 절차서대로 일해요.
3. **결과를 보고 절차서를 고쳐요.** 다음엔 더 잘해요. 같은 지시를 반복하는 대신 **방법 자체가 좋아져요.**
4. **잘 다듬어진 방법은 통째로 다음 프로젝트에 가져가요.**

> 코드 편집기·터미널·디버거도 들어 있어서 프로그램 개발에도 쓰지만, **개발 도구만은 아니에요.**
> 보고서·문서 작업, 시스템 전환 프로젝트, 데이터 정리, 웹 화면 테스트, 개인 지식 관리처럼
> "순서와 결과물이 있는 일"이라면 무엇이든 담을 수 있어요. → [활용 사례](use-cases.md)

## 이런 분께 좋아요

| 이런 분 | Studio 에서 할 수 있는 일 |
|---|---|
| 매주·매월 비슷한 문서를 만드는 분 | 보고서 만드는 절차를 한 번 정해 두고, 매번 AI 에게 맡긴 뒤 검토만 |
| 수십~수백 개 대상을 같은 방법으로 처리하는 분 | 대상 목록(작업 목록)을 만들고 체크해서 한꺼번에 실행, 진척 관리 |
| 시스템 전환·구축 프로젝트를 이끄는 분 | 방법론을 단계별 파이프라인으로 만들고, 팀과 AI 가 같은 방법으로 진행 |
| 웹 서비스를 테스트하는 분 | 브라우저에서 AI 가 화면·네트워크·콘솔을 함께 보며 문제를 찾고 기록 |
| 개발자 | 익숙한 VS Code 스타일 편집기·터미널·디버거 + 프로젝트를 아는 AI |
| 메모·지식을 쌓는 분 | Obsidian 호환 개인 노트, 프로젝트 위키, AI 가 기억하는 메모리 |

```
├──────┬──────────────────────────────────────┬──────────────┐
│ 아이콘 │  메인 화면                              │  AI 챗        │

│       ├──────────────────────────────────────┤  AI 가 붙어요  │
│  ⚙    │  하단: 터미널 · 로그 · 디버그 콘솔 · 문제  │              │
└──────┴──────────────────────────────────────┴──────────────┘
```

## 꼭 알아 둘 개념 다섯 가지

| 개념 | 쉽게 말하면 |
|---|---|
| **프로젝트** | 내 작업 폴더 하나. Studio 의 모든 정보는 그 폴더 안의 `.atlas/` 에 **파일로** 저장돼요 (서버·DB 없음) |
| **워크벤치** | "이 일을 하는 방법" 묶음 — 단계, 절차서, 도구, 안내문. 한 프로젝트에 여러 개를 둘 수 있어요 |
| **Stage (단계)** | 일을 크게 나눈 단계. 화면에서 탭 하나가 단계 하나예요 |
| **Activity (작업)** | 단계 안에서 실제로 실행하는 일 하나. AI 가 절차서대로 하거나, 프로그램·명령을 돌려요 |
| **작업 목록** | 처리할 대상(화면·문서·고객·할 일…) 목록. 체크해서 한꺼번에 실행하고 진척을 봐요 |

더 정확한 뜻은 [용어집](glossary.md) 에 있어요.

## 주요 기능

**AI 챗**
- 어느 화면에서든 쓸 수 있고, **지금 보고 있는 화면을 AI 가 알아요.** 화면을 옮겨도 대화가 이어져요.
- AI 는 파일을 읽고 쓰고, 명령을 실행하고, Studio 화면을 열어 보여 주기도 해요. 위험한 일은 먼저 물어봐요.
- 캡처한 이미지를 붙여넣어(Ctrl+V) 보여 줄 수 있어요.
- 반복 작업은 AI 가 **서브에이전트**에게 나눠 맡기고 요약만 받아 와요.
- AI 엔진(백엔드)은 두 가지 중 골라요: **Claude Code**(기본, Claude 계정 필요) 또는
  **[atlas-agent](../agent/README.md)**(사내·로컬 모델 포함 여러 AI 모델).

**일을 구조화하기**
- 단계(Stage)와 작업(Activity)으로 일을 나누고, 작업마다 절차서(skill.md)·입력 폼·선행 조건을 정해요.
- **Flow**: 여러 작업을 순서대로, 실패하면 다시 시도하도록 그림으로 이어요.
- **작업 목록**: 대상 목록을 체크하고 [실행] — 하나씩 또는 한꺼번에.
- **실행 기록**: 무엇이 언제 돌았고 어떻게 끝났는지 모두 남아요.

**지식이 쌓이는 곳**
- 메모리(사실), AGENT.md(항상 지킬 규칙), 가이드(절차), 위키(문서) — AI 와 사람이 함께 봐요.
- **변경 이력**: 파일이 저장될 때마다 그 버전이 남아서, 누가(사람·AI) 무엇을 바꿨는지 보고 되돌릴 수 있어요.
- **개인 노트**: 프로젝트와 상관없는 나만의 노트 (Obsidian 호환, 링크·태그·그래프 보기).

**편집과 개발**
- 파일 탐색기 + 코드 편집기(Monaco), 마크다운·HTML·JSON 미리보기, JSONL·JSON 을 표로 보기
- 빠른 전체 검색·치환, 통합 터미널, 디버거(Node·Python·Java 등), 정의로 이동(언어 서버)
- 옛날 인코딩(cp949) 파일도 그대로 읽고 저장

**확장**
- **브라우저 확장** (Chrome·Edge): 웹 페이지 옆에 AI 챗을 띄워 화면 테스트·조작·문제 진단
- **그래프 편집기**: [atlas-engine](../engine/README.md) 으로 데이터 처리 파이프라인을 그리고 실행
- **툴 만들기**: 코드 없이 폼·화면 도구를 선언하거나, 프로그램 도구를 만들어 AI 에게 쥐여 줘요
- **MCP**: 외부 도구 서버 연결

## 설치

1. [Releases](https://github.com/oranewbie/atlas-dist/releases) 에서 최신 `studio-v<버전>` 의 **`…-setup.exe`** 를 받아 실행해요.
   - 서명되지 않은 설치 파일이라 Windows SmartScreen 경고가 뜰 수 있어요 → **추가 정보 → 실행**.
   - Node 와 필요한 부품이 들어 있어 따로 준비할 건 없어요.
2. AI 를 쓰려면 둘 중 하나를 준비해요.
   - **Claude Code**(기본): 터미널에서 `claude` 로 로그인해 두면 돼요. Studio 는 로그인을 대신하지 않아요.
   - **atlas-agent**: 설정 ⚙ › 환경 설정 › 에이전트에서 바꾸면 설치·실행은 Studio 가 해요.
3. 새 버전이 나오면 아래 상태바에 알림이 떠요. **도움말 › 업데이트 확인** 으로 직접 확인할 수도 있어요.

자세한 첫 실행 과정은 [쉽게 따라하기](tutorial.md) 를 보세요.
