# Atlas Studio 단축키

> 기본값은 **VS Code 와 같은 관례**를 따라요. 메뉴와 명령 팔레트(Ctrl+Shift+P)에서도 항목 옆에 단축키가 보여요.
> macOS 의 `Cmd` 는 `Ctrl` 로 생각하시면 돼요.

## 1. 어디서나

| 키 | 동작 |
|---|---|
| `Ctrl+Shift+P` | 명령 팔레트 — 모든 명령 검색·실행 |
| `Ctrl+P` | 파일 빠른 열기 (프로젝트 전체, 최근 연 파일 먼저) |
| `` Ctrl+` `` | 하단 패널(터미널 등) 열기/닫기 |
| `Ctrl+R` | 지금 화면 새로 고침 (없으면 프로젝트 다시 읽기) |
| `Alt+←` / `Alt+→` | 뒤로 / 앞으로 (다녀온 화면) |
| `Alt+Home` | 홈 화면 (설정 ⚙ › 프로젝트 › 홈 화면) |

- **F5 는 새로 고침이 아니라 디버그 시작**이에요. 앱 전체가 새로 고쳐져 대화가 끊기는 일은 없어요.
- 마우스의 뒤로/앞으로 버튼도 `Alt+←` / `Alt+→` 와 같아요.

## 2. 파일

지금 화면이 지원할 때만 동작하고, 그럴 때만 파일 메뉴에 나타나요.

| 키 | 동작 |
|---|---|
| `Ctrl+N` | 새로 만들기 |
| `Ctrl+O` | 열기 |
| `Ctrl+S` | 저장 |
| `Ctrl+Shift+S` | 다른 이름으로 저장 |
| `Ctrl+W` | 닫기 |

## 3. 탐색기 트리

트리를 한 번 클릭해서 포커스를 준 뒤 써요.

| 키 | 동작 |
|---|---|
| `↑` `↓` | 위아래로 이동 |
| `→` / `←` | 폴더 펼치기 / 접기·부모로 |
| `Enter` | 열기 (폴더는 펼치기) |
| `F2` | 이름 바꾸기 |
| `Delete` | 삭제 (휴지통으로) |
| `Ctrl+A` | 보이는 항목 모두 선택 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 복사 / 잘라내기 / 붙여넣기 |
| `Ctrl+Z` | 파일 조작 되돌리기 (최근 50개, 삭제도 되살려요) |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 다시 하기 |

편집기 안에서 누른 `Ctrl+Z` 는 글자 편집을 되돌려요.

## 4. 디버그

| 키 | 동작 | 언제 |
|---|---|---|
| `F5` | 시작 / 멈춰 있으면 계속 | 실행 중이면 반응 없음 |
| `Shift+F5` | 중지 | 세션이 있을 때 |
| `Ctrl+Shift+F5` | 재시작 | 세션이 있을 때 |
| `F6` | 일시정지 | 실행 중 |
| `F10` | 한 단계 넘기기 | 멈춰 있을 때 |
| `F11` | 단계 안으로 | 멈춰 있을 때 |
| `Shift+F11` | 단계 밖으로 | 멈춰 있을 때 |

- F5 는 Run & Debug 에서 **고른 실행 구성**으로 시작해요. 구성이 없으면 Run & Debug 화면을 열어 만드는 법을 안내해요.
- F5 로는 세션을 두 개 띄울 수 없어요(실수로 서버를 두 번 띄워 포트가 겹치는 걸 막아요). 추가 세션은 사이드바의 **▶** 로 띄워요.
- 중단점은 편집기 줄 번호 옆을 클릭해요(전용 키 없음).

## 5. 통합 터미널

| 키 | 동작 |
|---|---|
| `Ctrl+Shift+C` | 선택한 글자 복사 |
| `Ctrl+Shift+V` | 붙여넣기 |
| `Ctrl+C` | **선택이 있으면** 복사, 없으면 실행 중인 명령 중단 |
| 우클릭 | 선택이 있으면 복사, 없으면 붙여넣기 |
| `Ctrl+R` | 셸의 명령 기록 검색 (Studio 새로 고침 아님) |

`Ctrl+C` 로 복사하면 선택이 바로 풀려요. 그래서 한 번 더 누르면 반드시 명령 중단이 돼요.

## 6. 작업(Activity) 목록

| 키 | 동작 |
|---|---|
| `↑` `↓` | 선택 이동 |
| `Enter` | 편집 화면 열기 |
| `Alt+↑` / `Alt+↓` | 선택한 작업의 순서 올리기 / 내리기 |

## 7. 챗

| 키 | 동작 |
|---|---|
| `/` | 작업(과 스킬) 목록 열기 → `↑` `↓` 로 고르고 `Enter` 실행, `Esc` 닫기 |
| `Ctrl+V` | 이미지(화면 캡처) 붙여넣어 첨부 |

## 8. 처리 순서 (참고)

키 하나가 여러 곳에 걸릴 때는 이 순서로 처리돼요.

1. Studio 기본 키(§1·§2)
2. 디버그·이동 키와 플러그인이 등록한 키
3. 편집기·터미널 자체 단축키
4. 새로 고침(`Ctrl+R`)

입력칸에 글을 쓰는 중에는 `Ctrl`·`Alt` 없는 키가 단축키로 동작하지 않아요(F 키는 예외).
