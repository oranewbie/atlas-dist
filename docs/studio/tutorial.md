# Atlas Studio 쉽게 따라하기 — 첫 프로젝트 30분

> 예제 프로젝트 **"주간 보고서 만들기"** 를 처음부터 끝까지 해 보며 Studio 의 기본 흐름
> **실행 → 평가 → 개선** 을 손에 익혀요. 코딩은 필요 없어요.
> 개념은 [용어집](glossary.md), 화면별 자세한 설명은 [사용자 매뉴얼](manual.md) 에 있어요.

> 💡 **가장 쉬운 방법: AI 에게 안내를 맡기세요.** 프로젝트를 만든 뒤 챗에
> **"따라하기 예제를 시작하자"** 라고 입력하면, AI 가 이 문서의 내용을 알고 한 단계씩 안내해요.
> 대신 해 줄 수 있는 건 해 주고, 직접 해 볼 곳은 짚어 줘요. 막히면 언제든 챗에 물어보세요.

## 0. 준비 (5분)

1. [Releases](https://github.com/oranewbie/atlas-dist/releases) 에서 `…-setup.exe` 를 받아 설치해요.
2. AI 를 준비해요 — 둘 중 하나면 돼요.
   - **Claude Code**(기본): 명령 프롬프트나 PowerShell 에서 `claude` 를 실행해 로그인해 두세요.
   - **atlas-agent**: Studio 를 연 뒤 **설정 ⚙ › 환경 설정 › 에이전트**에서 백엔드를 `atlas-agent` 로 바꾸고,
     **Config** 버튼으로 쓸 모델을 적어요. 설치·실행은 Studio 가 해요. ([모델 설정 방법](../agent/configuration.md#2-모델-연결하기))

## 1. 새 프로젝트 만들기

1. 타이틀바 **프로젝트 › 새 프로젝트…** 를 눌러요.
2. **프로젝트명**에 `weekly-report`, **폴더**는 [찾아보기]로 상위 폴더(예: `문서`)를 골라요.
   그 아래에 `weekly-report` 폴더가 만들어져요.
3. **작업자** 이름을 넣고 완료해요.

프로젝트가 열리면 왼쪽 아이콘 바, 가운데 화면, 챗 창이 보여요. 아직 단계가 하나도 없어서
**Activity** 화면에는 **'Activity 구성' 시작 페이지**가 떠 있어요(? 아이콘을 누르면 이 화면 설명이 나와요).

> 처음엔 왼쪽에 아이콘이 6개만 보여요(탐색기 · 찾기 · Run & Debug · 작업 목록 · Activity · 툴).
> 다른 화면은 아이콘 바를 **우클릭**해서 켤 수 있어요.

## 2. AI 와 일하는 방법 정하기

챗에 이렇게 말해요.

> **"매주 팀 주간 보고서를 만드는 작업 파이프라인을 설계해 줘"**

AI 가 몇 가지를 물어봐요. 예제 답:

- **목표**: 매주 팀 주간 보고서를 쓴다.
- **단계**: ① 재료 모으기(한 주의 작업 메모) → ② 초안 쓰기(보고서 md 파일) → ③ 검토하기
- **완료 기준**: 보고서에 *지난주 성과 · 이번 주 계획 · 리스크* 세 절이 있고, 검토자가 승인한다.

답을 다 하면 AI 가 단계와 작업을 만들어요. **Activity 화면에 단계 탭**이 생겼는지 확인해 보세요.
탭 하나가 단계 하나이고, 탭 안의 목록 한 줄이 작업(Activity) 하나예요.

## 3. 재료 넣기

첫 단계(재료 모으기)에서 쓸 이번 주 작업 메모를 2~3개 만들어요.
직접 써도 되고, 챗에 **"예시 재료 메모를 만들어 줘"** 라고 해도 돼요.
AI 가 파일을 만들고 탐색기로 열어 보여 줘요.

## 4. 실행하기 — 초안 쓰기

1. 초안 쓰기 단계 탭을 열어요.
2. 초안 작업 줄 맨 앞의 **👁** 를 눌러 오른쪽에 상세를 열어요.
3. 아래쪽 **▶ 실행** 을 눌러요. AI 가 이 작업의 절차서(skill.md)대로 일해요.
4. 끝나면 **📂 결과** 버튼으로 만들어진 보고서를 열어요.
   마크다운 파일은 편집기 위쪽의 **미리보기** 토글로 인쇄될 모양 그대로 볼 수 있어요.

> 자주 쓰는 작업은 상세의 **☑ 실행버튼 보이기**를 켜 두세요. 그러면 챗 입력창에 **`/`** 만 쳐도 목록에 떠서 바로 실행할 수 있어요.

## 5. 평가하기

검토(평가) 작업을 실행하면 AI 가 결과물을 완료 기준에 비추어 점검하고 **부족한 점**을 결과로 남겨요.
"무엇이 모자란가"를 사람이 일일이 짚지 않아도 평가가 쌓이는 게 포인트예요.

## 6. 개선하기 — 방법이 좋아지는 순간

챗에 이렇게 말해요.

> **"평가 결과를 반영해서 초안 쓰기 절차를 고쳐 줘"**

AI 가 평가 내용과 여러분의 의견을 읽고 **절차서(skill.md) 자체를 고쳐요.**
그다음 초안 작업을 다시 실행해서 결과가 나아졌는지 보세요.

같은 지시를 매번 반복하는 대신 **절차가 자라는 것** — 이게 Studio 의 핵심이에요.

## 7. 마무리

- 완료 확인은 사람이 결과물을 보고 해요.
- 무엇이 언제 돌았는지는 **실행 기록** 화면에서 볼 수 있어요(아이콘 바 우클릭 → 실행 기록).
- AI 가 고친 파일과 이전 버전은 **변경 이력** 화면, 또는 탐색기 아래 **타임라인**에서 보고 되돌릴 수 있어요.

## 8. 더 해 보기 (선택)

| 해 볼 것 | 어떻게 |
|---|---|
| **입력 폼 달기** | 챗에 "초안 작업을 실행할 때 주차를 입력받게 해 줘" — 다음 실행부터 폼이 먼저 떠요 |
| **여러 주 한꺼번에** | **작업 목록**에 주차들을 넣고, 체크해서 [실행] |
| **흐름으로 잇기** | 단계 화면 오른쪽 **Flow** 탭에서 "초안 → 검토 → 실패하면 다시 초안(최대 3번)" 을 그려요 |
| **폼 도구 만들기** | 툴 패널(🛠)에서 "보고 대상 주를 고르는 폼 도구를 만들어 줘" — 코드 없이 폼이 생기고, AI 가 일하다가 띄워요 |
| **규칙 정해 두기** | "보고서는 앞으로 항상 존댓말로 써 줘" — `.atlas/AGENT.md` 에 적혀 모든 대화에 적용돼요 |
| **방법을 템플릿으로** | 충분히 다듬어졌다면 "이 워크벤치를 템플릿으로 내보내 줘" — 다음 프로젝트에서 이 방법으로 바로 시작해요 |
