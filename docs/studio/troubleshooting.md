# Atlas Studio 문제 해결

> 막히면 **챗에 그대로 물어보는 게 가장 빨라요.** AI 가 Studio 의 설치·설정 가이드를 읽고 답해요.
> 앱 안의 **도움말 › 도움말 문서… › 가이드**(설정 / 에이전트 백엔드 준비 / 구성 요소 설치 / 브라우저 연동 설치)에도
> 증상별 조치가 있어요. 명령으로는 `atlas guide settings` · `agent-setup` · `components` · `browser-setup`.

## 어디를 보면 되나

| 무엇 | 위치 |
|---|---|
| 실패한 대화·실행 | 하단 패널 **문제** 탭 |
| 앱·AI 진단 로그 | 하단 패널 **로그** 탭 |
| atlas-agent 서버 로그 | `~/.atlas/agent-server.log` |
| 그래프 엔진 로그 | `~/.atlas/engine.log` |
| Java 디버그(JDT LS) 로그 | `~/.atlas/jdtls.log` |
| 실행 기록 | **실행 기록** 화면, `atlas activity jobs` |

`~` 는 내 사용자 폴더(`C:\Users\<이름>`)예요.

## 설치·업데이트

| 증상 | 해결 |
|---|---|
| 설치할 때 "Windows 의 PC 보호" 경고 | 서명 안 된 설치 파일이라 그래요. **추가 정보 → 실행** |
| 업데이트 알림이 안 떠요 | 버전마다 한 번만 떠요. **도움말 › 업데이트 확인** 으로 직접 확인 |

## AI 챗

| 증상 | 해결 |
|---|---|
| 대화가 실패해요 | 실패 안내 아래 **백엔드 진단 N줄** 을 펼치면 원래 오류가 보여요. **문제**·**로그** 탭에도 있어요 |
| "⚠ Claude 인증이 만료됐습니다" | Claude 로그인이 풀렸어요. 카드의 **[터미널에서 로그인]** → 로그인 후 **메시지를 다시 보내면** 이어져요. 다른 계정은 설정 ⚙ › 환경 설정 › 에이전트 |
| AI 가 대답 없이 멈춘 것 같아요 | 챗 위쪽에 **승인 카드**가 기다리고 있지 않은지 보세요 |
| atlas-agent 로 바꿨는데 모델 선택이 없어요 | 정상이에요. 모델은 atlas-agent 설정 파일이 정해요 — 에이전트 탭의 **Config** |
| atlas-agent 에서 기본 모델을 골랐는데 안 바뀌어요 | 현재 알려진 제한이에요. **Config** 로 설정 파일의 `prefer_model_config` 를 고치세요 |
| atlas-agent 서버가 안 떠요 | 설정 ⚙ › 구성 요소 › **에이전트 서버** 카드에서 상태 확인·재시작. 번들과 같은 **Python 3.12** 가 PC 에 있어야 설치돼요. 로그 `~/.atlas/agent-server.log` |
| 워크벤치를 바꿨는데 AI 가 예전 내용을 말해요 | 열려 있던 대화는 바꾸기 전 맥락을 써요. **＋ 새 대화**로 시작하세요 |
| 대화 이력이 사라졌어요 | 프로젝트를 옮겼어도 `.atlas/private/agent/chats` 가 있으면 복원돼요. 복원 못 한 대화는 새 대화로 시작돼요(로그에 경고) |
| MCP 서버 도구가 안 보여요 | 툴 패널 MCP 섹션에서 **켜져** 있는지, 그리고 **새 대화**를 열었는지 확인 |

## 작업·실행

| 증상 | 해결 |
|---|---|
| ▶ 를 눌러도 실행이 안 돼요 | 상세에 **⏸ 선행 대기**가 보이면 앞 작업을 먼저 끝내야 해요. 입력 폼의 필수 값도 확인 |
| Flow 를 실행하니 "비어 있는 노드" 오류 | 아직 작업이 연결되지 않은 빈 노드가 있어요. 속성 창에서 작업을 만들거나 연결하세요 |
| 작업 순서를 끌어도 안 움직여요 | 정렬이나 필터가 걸려 있으면 순서를 못 바꿔요. 풀고 다시 해 보세요 |
| 툴 실행이 "외부 패키지를 준비할 수 없습니다" 로 실패 | 패키지 설치가 실패했어요. 네트워크, 패키지 이름, 컴파일이 필요한 패키지인지 확인하세요(순수 JavaScript 패키지만 돼요). 로그에 npm 출력이 남아요 |
| 작업 목록에서 항목을 고칠 수 없어요 | 파일·툴에서 가져온 목록은 원천이 주인이에요. 원천을 고치거나 AI 에게 부탁하세요 |

## 편집기·검색

| 증상 | 해결 |
|---|---|
| 화면이 오래된 내용을 보여요 | `Ctrl+R` 또는 **프로젝트 › 다시 읽기** |
| "⚠ 디스크에서 변경됨 — 편집 중이라 반영하지 않았습니다" | 내가 고치는 중인 파일을 밖에서도 바꿨어요. 저장하면 밖의 변경을 덮어써요 — 확인하고 결정하세요 |
| Ctrl+클릭으로 정의로 이동이 안 돼요 | 그 언어의 언어 서버가 필요해요. 설정 ⚙ › 환경 설정 › **언어 서버**에서 설치(`atlas lsp list` 로 상태 확인) |
| `.atlas` 안의 내용이 검색에 안 나와요 | 찾기의 **작업 폴더(.atlas) 제외** 토글을 끄세요 |
| 한글 파일이 깨져 보여요 | 편집기 오른쪽 위의 인코딩 표시에서 `cp949` 등으로 다시 열어 보세요 |

## 그래프·디버그

| 증상 | 해결 |
|---|---|
| 그래프 실행이 안 돼요 | 설정 ⚙ › 구성 요소 › **그래프 엔진** 카드에서 상태·설치 확인. 로그 `~/.atlas/engine.log`. 환경 변수 `ATLAS_ENGINE_AUTOSTART=0` 을 설정했다면 지우세요 |
| "Python 환경을 준비하세요" 로 실행이 거부돼요 | 그래프 목록의 **Python 환경**에서 **준비** 를 누르세요(requirements 를 고친 뒤에도 다시) |
| 노드 디버그(🐞)가 연결되지 않아요 | 그 노드가 쓰는 Python 에 `debugpy` 가 있어야 해요. Studio 가 만든 환경엔 자동으로 들어가요 |
| Java 디버그가 안 붙어요 | 디버그 어댑터 설치 여부, **JDK 17 이상**, 첫 실행은 프로젝트 읽기로 수십 초 걸려요(디버그 콘솔에 진행 표시). 로그 `~/.atlas/jdtls.log` |
| F5 를 눌러도 반응이 없어요 | 이미 디버그가 실행 중이에요. 추가 세션은 Run & Debug 의 **▶** |

## 브라우저 확장

| 증상 | 해결 |
|---|---|
| 확장이 설치되지 않아요 | 브라우저가 외부 설치를 막아요. 설정 ⚙ › **브라우저 연동** 으로 폴더를 준비한 뒤, 확장 페이지에서 **압축해제된 확장 프로그램 로드**로 직접 한 번 등록하세요 |
| "…이 브라우저를 디버깅하고 있습니다" 배너가 떠요 | 네트워크·콘솔 수집 중이라는 표시예요. 없애려면 패널 ⚙ → **네트워크·콘솔 자동 수집** 끄기 |
| 이미 난 오류를 AI 가 못 봐요 | 수집은 붙은 뒤부터예요. 한 번 더 재현해 주세요 |
| 사이드 패널로 옮기려니 "툴바 아이콘을 클릭하세요" | 브라우저가 사이드 패널 열기를 직접 클릭에만 허용해요. 아이콘을 눌러 주세요 |

## 그래도 안 되면

챗에 증상과 **문제·로그 탭의 내용**을 함께 붙여 물어보세요. Studio 자체의 버그 같다면 "이거 Studio 버그 같아"라고 말해 주세요 —
피드백으로 기록되어 제품 개선에 쓰여요(`atlas lab list`).
