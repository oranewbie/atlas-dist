## Atlas Studio

### 0.1.27 ~ 0.1.29 (2026-09 ~ 10)

- **에이전트 프로파일**: "백엔드 + 모델" 조합에 이름을 붙여 작업마다 다른 AI 를 쓸 수 있어요 (`atlas agents …`).
- **기본 모델** 칸을 두 백엔드가 함께 써요. Claude Code 는 설치된 버전에 직접 물어 모델 목록을 받아 와요.
- atlas-agent 백엔드: 승인 카드에 이유·명령·경로 표시, **항상 허용** 범위(대화 / 이 PC / 프로젝트), **권한 모드**(기본 / 편집 허용 / 계획),
  챗 `/` 목록에 프로젝트 스킬 표시.
- **라이트 테마** 추가 (다크가 기본).
- Activity 화면이 **표 형태 목록**으로 바뀌었어요 — 손잡이로 순서 바꾸기, `Alt+↑/↓`, 상세는 👁 로 열기.
- Flow: 여러 단계를 잇는 흐름, 팔레트 접기, 되돌리기가 노드 위치까지.
- 처음엔 아이콘 6개만 보이고 나머지는 아이콘 바 우클릭으로 켜요.
- 탐색기: 상위 폴더 고정, 큰 폴더 나눠 그리기, 사이드바 접기. 찾기 결과에 **파일 이름** 섹션.
- 디버그 어댑터 카드에서 **VS Code 확장(.vsix) 추가**.
- 브라우저 확장 패널이 탭 4개(대화 · 관련 소스 · 탐색기 · 검색)로 정리됐어요.

### 0.1.21 ~ 0.1.26 (2026-09)

- **미리보기**: 마크다운·HTML·SVG 미리보기, JSON·XML 트리 보기.
- `.atlas/` 폴더가 **팀 공유(바로 아래) / 나만(`private/`)** 으로 정리됐어요. git 제외 규칙을 Studio 가 관리해요.
- 탐색기 **복사·붙여넣기·되돌리기**, 키보드 조작, 끌어 옮기기, 탭 복원, 자동 저장, **분할 편집**, **cp949 등 옛 인코딩 유지 저장**.
- 새 프로젝트 위저드가 단순해졌어요(이름·폴더·작업자만). 템플릿은 설정 › 프로젝트 › 워크벤치에서.
- 설정의 "Atlas 제품"이 **"구성 요소"** 로 바뀌고 [업데이트 확인]이 생겼어요.
- 챗: **캡처 붙여넣기 첨부**, 응답 MD/텍스트 복사, 걸린 시간 표시, 링크 열기, Claude 인증 만료 안내.
- 작업 목록: 사용 끔, 일괄 삭제, 표에서 바로 편집, 실행 화면 2단 구성. 실행 방식은 연결한 작업이 정해요.
- `atlas infer`(도구 없이 한 번 묻기), 통합 터미널에서 `atlas`·`atlas-engine`·`atlas-agent` 바로 실행.
- 앱 안 **도움말 가이드**(설정 · 에이전트 백엔드 준비 · 구성 요소 설치 · 브라우저 연동 설치).

### 0.1.12 ~ 0.1.17 (2026-08)

- 새 화면: **작업 목록**, **변경 이력**(파일 버전 타임라인), **실행 기록**.
- **작업 지시서**: "무엇(대상) × 어떻게(지시서)" 로 여러 대상을 한꺼번에 실행.
- Flow 의 **반복·분기**(실패 시 분기, 되돌아가기, 재시도 횟수, 사람 개입), **격리 실행(worktree)**, 입력 폼.
- 내장 작업 **가이드 물어보기 · 소스 매뉴얼화**, 스킬 내보내기(`atlas skill export`).
- **서브에이전트** 진행 보기와 함께 멈추기. **AGENT.md**(항상 지킬 규칙), Studio 개선 랩.
- **정의로 이동(Ctrl+클릭)** 과 언어 서버 설치.
- 타이틀바 **← → ⟳ ⌂** 와 `Alt+←/→/Home`. Ctrl+P 가 프로젝트 전체 대상.
- 찾기: 대소문자·단어·정규식, 포함/제외 조건 창, 검색 중단.
- 한 프로젝트에 **워크벤치 여러 개**와 타이틀바 피커.
- **표시 언어 전환**(한국어 · English)과 언어 팩 추가.
- 브라우저 확장: **별도 창**, **네트워크·콘솔 자동 수집**, 관련 소스 기록.
- **없어진 것**: VS Code 연동 확장(0.1.13), 라이선스 등록 화면(0.1.16), Stage 의 Hooks·피드백·Todo 탭(0.1.15).

### 0.1.6 ~ 0.1.11 (2026-07 ~ 08)

- **개인 노트**(Obsidian 호환, 링크·태그·그래프·데일리 노트).
- 앱 안 **도움말 문서** 창, 용어집·따라하기 문서.
- 디버그 단축키(F5 계열). F5 는 새로 고침이 아니라 디버그 시작이에요.
- 그래프 편집기 **Python 환경**(venv), 툴 **외부 패키지(npm)** 자동 설치.
- 터미널 복사·붙여넣기 키, 대화 탭바 정리.
